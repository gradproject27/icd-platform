| RV1-D2 | 25 Nov 2026 | Event confidence `C_i` is no longer a fixed value per dataset. It is a calibrated hybrid: (1) a classifier on flow features gives each flagged event a probability, calibrated with isotonic regression; (2) the LLM gives a calibrated opinion per evidence group (5 samples or token probabilities, Platt scaling); (3) a logistic-regression stacker combines them; (4) split conformal prediction at 95% marks uncertain events `needs_review`; (5) `C` is kept between 0.05 and 1; (6) without an LLM opinion, `C` = the classifier's value with a flag.
